# Azeroth Rivals: versiones

Aquí se publican las versiones jugables de **Azeroth Rivals**, un brawler de arena visto desde arriba con temática de World of Warcraft.

Este repositorio solo guarda las versiones. El código no está aquí.

## Cómo jugar

1. Entra en **Releases** (a la derecha) y descarga el `.exe` de la última versión.
2. Ábrelo. Como el archivo no está firmado, Windows puede avisar. Pulsa «Más información» y luego «Ejecutar de todas formas».
3. Cuando salga una versión nueva, el menú del juego te avisa y se actualiza con un botón.

## Aviso

- Es una alpha: puede tener fallos y cambiar mucho de una versión a otra.
- Proyecto de fans, sin relación con Blizzard Entertainment. World of Warcraft es una marca de Blizzard Entertainment.
